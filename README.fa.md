# پردازش گفتار · دانشگاه علم و صنعت ایران

## ساخت جزوه از منبع

فایل PDF آمادهٔ مطالعه است. برای ویرایش و ساخت دوباره، **TeX Live یا MacTeX** را همراه با **XeLaTeX**، **latexmk** و بسته‌های استفاده‌شده در [فایل اصلی](slp-booklet/latex/main.tex)، از جمله `xepersian`، نصب کنید. فونت‌ها و شکل‌های موردنیاز در مخزن قرار دارند.

</div>

```bash
git clone git@github.com:AmirHosseinCV/slp-iust.git
cd slp-iust/slp-booklet
make
```

<div dir="rtl">

خروجی در `build/main.pdf` ساخته می‌شود و فایل [`speech-processing-booklet-fa-draft.pdf`](slp-booklet/speech-processing-booklet-fa-draft.pdf) را به‌روز می‌کند. راهنمای ساخت یک فصل در [راهنمای جزوه](slp-booklet/README.md) آمده است.
